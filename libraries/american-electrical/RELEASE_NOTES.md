# American Electrical fuse holders: release notes

This library has its own version number (MAJOR.COMMIT.CHANGE), separate from DIN Stack's. Versions are listed newest first. DIN Stack's own changes are in the main [release notes](../../RELEASE_NOTES.md).

To get a newer version into a diagram, click **+** beside the library drop-down and use **Refresh** next to the library. It's highlighted when the diagram has an older version.

## 1.0.1 — 2026-10-26

- New library with 8 types: American Electrical (AEI) DIN-rail fuse holders for 10 × 38 mm (midget) fuses, 30 A 600 V, made by ETI as the EFD 10:
  - **Non-indicating:** 2540001 (1-pole), 2540002 (1-pole + N), 2540003 (2-pole), 2540004 (3-pole), 2540005 (3-pole + N).
  - **LED indicating:** 2540011 (1-pole), 2540013 (2-pole), 2540014 (3-pole).
- Which side is the neutral, and 2540005 being 3-pole + N, are assumptions; see the [library guide](../../docs/library.md#libraries-that-come-with-din-stack).
