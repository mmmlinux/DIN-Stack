How to use DIN Stack

The screen

  • Library (left): the object types you can place. Inspector (right): whatever is selected, or the diagram itself when nothing is. Lists (bottom): wires, cables, bus bars and parts.
  • Right-click empty space on the drawing to add a rail, note, bus bar or cable. The wire button at the bottom right, beside the zoom buttons, picks how wires are drawn: Stubs at each terminal, or Straight or Curved lines. Its Labels tick box shows where each wire goes at its terminals, Wire names adds the wire's number, and Named circuits show picks a named circuit's name or where its wires go.
  • The cable button beside it sets how cables look: Full length, or Broken (tails), a short tail at each end labelled with where the other end goes (e.g. K1), so long cables don't cross the drawing. Cable names (off unless you tick it) adds the cable's name: C1 → K1 at a break, and along the sheath before its type.
  • Each wire can be drawn differently from the rest: select it (or several) and set Draw as to a line to the other end, or Broken, a stub at each end labelled with where it goes. Handy for breaking just the long runs when wires are drawn as lines, or drawing a short jumper as a line when they're stubs. A cable's Draw setting does the same for that cable. Both are also on the right-click menu.
  • Settings (the sliders button at the top) holds the snap grid, text sizes, wire standard, terminal reference style and build direction.

Placing things

  • Click an object in the library (or drag it onto the drawing) to add it. With a part selected, the new one lands flush beside it in the build direction.
  • The drop-down at the top of the library picks which library is shown: Built-in, My types, each imported library, or All libraries. The + next to it opens the library manager, which loads, unloads and refreshes the libraries that come with DIN Stack, or imports a library file. ⋯ exports the library shown.
  • Categories start folded, so a library first shows just their names. Click a category's name to open or fold it, or use the fold button beside the search box to open or fold them all. Searching still shows every match. « hides the library panel for more drawing space.
  • Drag parts to move them. They snap flush against neighbours and centre on DIN rails. Hold Alt while dragging to place freely.
  • Hold Ctrl (Cmd on a Mac) while dragging to push the parts touching it on that side along with it, e.g. to open a gap in a terminal strip. Anything past a gap stays put, and the move is kept straight. Add Alt to move freely.
  • Shift-click to select several, or Shift-drag on empty space to box-select. Drag empty space to pan, use the mouse wheel to zoom.
  • With several things selected, the panel has a section for each kind (wires, bus bars, cables, parts, rails, notes) with the settings they share. A change there applies to all of that kind in the selection. A setting they don't share shows as Mixed until you change it.

Terminal strips

  • Select a terminal block and use Repeat under Strip in the inspector to add numbered copies.
  • To renumber, select several parts (Shift-click, Shift-drag, or All of this type / All “TB…” on a part), then use Renumber tags. They're numbered in position order and their wires stay connected.
  • The Left → right / Right → left toggle sets which way strips grow: new parts added beside the selected one, repeats, and Pack side by side.

Wiring

  • Drag from one terminal to another, or click one terminal and then another.
  • Terminals are referenced as part tag plus terminal name, e.g. TB101-1 (change the separator in Settings).
  • The wire button at the bottom right of the drawing sets how wires look. Stubs draws a short stub at each terminal; Straight lines and Curved lines draw lines between the terminals. With Labels ticked, each terminal shows where its wire goes, e.g. TB101-1. Wire names (off unless you tick it) adds the wire's number in front of the label with stubs (W3 → TB101-1), or at the middle of each line. Under Named circuits show, Circuit name shows the circuit's name instead of where the wire goes (+24V), at each end of the wire as that label would be, with stubs or lines; a wire in an unnamed circuit shows where it goes (TB101-1). Each named circuit can override this with Circuit's labels show in the Circuit section of a wire's panel, e.g. to label only +24V and 0V with their names, and each wire with This wire's label shows. The printout and exported images follow the same settings.
  • The selection filter (the funnel at the bottom right, beside the wire button) limits what you can select, e.g. only wires, or only wires and cables. Pick one kind for only that; with a filter on, each tick adds or removes a kind. While it's on, the cursor changes, clicks pick only those kinds, and dragging on empty space draws a selection box that picks up those kinds, including wires, bus bars and cables with an end in the box. Space or Esc turns it off (Esc keeps what you selected).
  • Show only these wires (right-click selected wires, or under Wiring in the right panel) hides every other wire on the drawing, to follow a few at a time. The view tools at the bottom right show how many are shown; click Show all there to bring the rest back. Printouts and exported images always include every wire.
  • Click a label or line to set the wire number, colour, size and notes in the inspector.
  • Stripe adds a tracer stripe, e.g. red with a white stripe. It's drawn as short dashes over the base colour and listed as "Red/White".
  • Wire profiles (e.g. "+24 V DC, red, 1.5 mm², stranded") are named wire types. Edit them from the inspector with nothing selected, or with Edit… next to a wire's profile. Assign one to a wire, or to several selected wires at once. Editing a profile updates all its wires.
  • A new wire added to a circuit that already has wires matches them (profile, colour, size, conductor) and keeps following: change the feed wire by hand and the matching wires change with it. Changing a wire by hand stops it following; tick Match the circuit to turn it back on. Bus bars work the same way for their colour.
  • Wire standard in Settings switches between metric (mm², brown line, blue neutral, green/yellow earth) and American (AWG, black hot, white neutral, green ground). Existing wires and profiles are converted to the nearest size.

Cables

  • Every cable has two ends, and each is plugged into a cable connector, fans out into cores that land on terminals, or is free, running off the drawing. Any two go together: connector to connector (a patch lead), connector to fan-out (a motor cable into the motor's socket), or fan-out to fan-out (wires bundled into a cable). The Ends section of a cable's panel, and its right-click menu, change either end: Plug into a connector…, Fan out to terminals…, Unplug, Leave free or Add cores….
  • Select the wires that run in one cable (Shift+click, or right-click → Bundle into a cable). They're drawn as a sheath that fans out into the coloured cores at each end. Give the cable a label and description (e.g. 3G1.5), and drag the orange dots on a selected cable to move where the cores fan out. When you move the parts at one end of a cable, that end's fan-out point moves with them; move the parts at both ends and the whole cable moves.
  • For a cable coming in from outside, put a loose part such as the Mains plug at the far end.
  • Cable connectors are sockets that take a cable's plug rather than single wires, such as the RJ45 ports on an Ethernet switch or the socket on a motor. Drag from one connector to another to plug a cable in between them, as with a patch lead, or from a connector to a terminal for a cable plugged in at one end with a core landing on the terminal. Right-click a connector for Plug in a cable…, Select cable or Unplug the cable.
  • A cable whose cores land on terminals can plug into a connector at its other end, such as a motor cable from a drive's U, V, W and PE to the motor's socket. While picking its terminals, click the connector too, or use Plug into a connector… on its other end. Plugging in or freeing one end of a bundle of wires takes them off their terminals at that end: they become the cable's cores (you're asked first).
  • Cable profiles are named cable types: sheath colour, type (e.g. Cat6 S/FTP), Shielded, Twisted pairs and notes. Pick one under Cable profile in a cable's panel, and edit them with Edit cable profiles… (in the right panel with nothing selected). A shielded cable is drawn with a dashed outline along its sheath.
  • Cores in a cable profile: click Cores on a cable profile to list the cores it contains, in order, each with a marking (e.g. 1, 2… on numbered cores), colour, stripe, size and conductor. A cable given that profile gives its cores those looks, core 1 first, and editing them updates its cables. A core changed by hand keeps its own look until the profile is picked for the cable again. With no cores listed, the wires inside a cable keep their own looks. A patch lead lists its profile's cores in its panel, and when you fan out one of its ends, the bar at the top says which core comes next.
  • One-ended cables: when the other end isn't on the drawing, right-click empty space → Cable… (or right-click a terminal → Cable from here…), click the terminals its cores go to, and press Enter or Done in the bar at the top. The sheath runs off to a free end; fill in Goes to (e.g. "Pump P1") to label it. Each core is a wire, referenced as C1-1, C1-2…
  • Drawing the other end later: right-click the cable → Fan out to terminals… under its free or plugged-in end (also in its panel's Ends section), then click the terminal each core goes to, in core order: core 1, then core 2, and so on. The bar at the top says which core is next. Press Enter or Done once every core has a terminal, and the cable is drawn with both ends, like wires bundled into a cable.

Bus bars

  • Right-click empty space → Bus bar… (or right-click a terminal → Bus bar from here…), then click the terminals to bridge (or drag along a row), and press Enter or Done. The bar is drawn through them and counts as part of the circuit.
  • Terminal blocks have two bus bar slots (the small squares in the middle) that take bus bars but not wires. To bridge alternate blocks, sweep along a row of slots, then click Keep 1st, 3rd… or Keep 2nd, 4th…. A dot marks each block a bar connects to, so a bar passing over a block without a dot skips it.

Circuits

  • A selected wire also lights up the rest of its circuit in lighter blue: every wire connected to it, including through the other side of a terminal block. Which terminals are connected inside a part is set with Link in the object type designer.
  • Select whole circuit selects everything in it. Select daisy chain selects only the wires and bus bars joined at the same terminals, such as a jumper chain along the tops of a strip, without crossing to the other side of the terminal blocks.
  • Circuit names: select a wire and type a Circuit name (e.g. +24V). The whole circuit takes the name, and it shows in the wire list.
  • Circuit name or where it goes: Circuit's labels show picks whether a named circuit's wires are labelled with its name (+24V) or with where each wire goes (TB101-1). This wire's label shows overrides that for one wire, so most of a +24V circuit can just say +24V while the wires you care about show where they land. Right-click wires → Label shows does the same for several at once.
  • Connector labels: select a part and type a label next to a terminal under Terminals. The label is drawn at the terminal as a boxed tag, so you don't have to draw a wire from where it comes from (handy for power feeds). Terminals and wires with the same name are treated as one circuit.

Your own objects

  • + New type opens the designer. Set the size in millimetres, then click where each terminal goes, or add a whole row or grid at once.
  • Add a grid places blocks like a 2 × 16 header or an IC. Numbering can wrap by rows or columns, go around like an IC (counter-clockwise or clockwise), or use row letters (A1… B1…), starting from any corner.
  • In the designer, drag over empty space to select several terminals, then drag one of them to move them all. Shift+click adds to the selection, the arrow keys nudge, Ctrl+D copies, Delete removes, and Ctrl+Z undoes.
  • Set Mounting to Loose for parts that aren't on a DIN rail, like connectors on the enclosure. The library's Enclosure connectors group has some ready-made ones (tag prefix X).
  • Give terminals the same Link value when they're connected inside the part, such as both sides of a terminal block or a power supply's two +V terminals. Set a terminal's Type to Bus bar slot for a point that takes bus bars only, or to Cable connector for a socket that takes a cable's plug rather than single wires, such as an RJ45 port.
  • Editing a type updates every part that uses it.
  • The library guide covers every setting, a worked example, sharing libraries and the file format.

Right-click menus

  • Right-click a part, terminal, wire, bus bar, cable, rail or note for the things you can do with it. Right-click empty space to paste there, add a rail or note there, undo or fit the view.
  • Right-clicking something already in a multiple selection keeps the selection, so the menu applies to all of it.

Welcome to DIN Stack

Document DIN rail wiring with parts at their real size. Here's how to get going.

  1. Place parts

    Click a type in the library on the left, or drag it onto the drawing. Parts snap flush against each other and centre on DIN rails. Right-click empty space on the drawing to add rails, notes, bus bars and cables.

  2. Wire them up

    Drag from one terminal to another. Each terminal is labelled with where its wire goes, and the wire list below fills in as you go.

  3. Edit anything

    Click a part, wire or bus bar to change it in the inspector on the right. Right-click it for more.

  4. Keep your work

    Everything is saved in this browser automatically. Use File → Save for a file you can open elsewhere, and Export to print or make images.

Included libraries

Ready-made libraries that come with DIN Stack. Load adds one to this diagram as its own library, picked with the drop-down at the top of the library. Refresh loads it again to pick up changes; it's highlighted when a newer version is out. Unload removes it, along with any parts that use its types. All of these can be undone.

Wire and cable profiles

A profile is a named wire type. Wires assigned to a profile take its colour, stripe, size and conductor, and editing a profile here updates all of them. Changing a wire by hand makes it a custom wire again.

Cable profiles

A cable profile is a named cable type: its sheath colour, type (e.g. Cat6 S/FTP), whether it's shielded or has twisted pairs, any notes, and the cores it contains. Cables assigned to a profile follow it, and editing it here updates all of them. Click Cores to list its cores in order, each with a marking, colour, stripe, size and conductor: a cable's cores then take those looks, core 1 first. With no cores listed, the wires inside a cable keep their own looks.
