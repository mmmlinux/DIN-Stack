How to use DIN Stack

Placing things

  • Click an object in the library (or drag it onto the canvas) to add it.
  • Click a library category's name to fold it away, or ⊟ to fold them all. Searching still shows every match. « next to + New type hides the library panel for more drawing space; » brings it back. Rails, notes, bus bars and cables are added from Add in the toolbar.
  • Drag parts to move them. They snap flush against neighbours and centre on DIN rails. Hold Alt while dragging to place freely.
  • Hold Ctrl (Cmd on a Mac) while dragging to push the parts touching it on that side along with it (and the ones touching those), e.g. to open a gap in a terminal strip. Anything past a gap stays put, and the move is kept straight. The whole moving group snaps against the parts it moves towards or away from, so it can close up flush with the next part. Add Alt to move freely.
  • Shift-click to select several, or Shift-drag on empty space to box-select.
  • Drag empty space to pan, use the mouse wheel to zoom.
  • Select a terminal block and use Repeat to build a strip with numbered tags.
  • To renumber, select several parts (Shift-click, Shift-drag, or All of this type / All “TB…” on a part), then use Renumber tags. They're numbered in position order and their wires stay connected.
  • The Left → right / Right → left toggle sets which way strips grow: new parts added beside the selected one, repeats, and Pack side by side.

Wiring

  • Drag from one terminal to another, or click one terminal and then another.
  • Terminals are referenced as part tag plus terminal name, e.g. TB101-1 (change the separator under Display).
  • Each terminal shows where its wire goes, e.g. W3 → TB101-1. Choose Wires in the toolbar to draw lines as well.
  • Click a label or line to set the wire number, colour, size and notes.
  • Stripe on a wire's panel adds a tracer stripe, e.g. red with a white stripe. It's drawn as short dashes over the base colour and listed as "Red/White". Profiles can have a stripe too.
  • Wire profiles (e.g. "+24 V DC, red, 1.5 mm², stranded") are set up under Edit wire profiles… with nothing selected. Assign one to a wire, or to several selected wires at once. Editing a profile updates all its wires.
  • A new wire added to a circuit that already has wires matches them (profile, colour, size, conductor) and keeps following: change the feed wire by hand and the matching wires change with it. Changing a wire by hand stops it following; tick Match the circuit to turn it back on. Bus bars work the same way for their colour.
  • Wire standard under Display switches between metric (mm², brown line, blue neutral, green/yellow earth) and American (AWG, black hot, white neutral, green ground). Existing wires and profiles are converted to the nearest size.
  • Cables: select the wires that run in one cable (Shift+click, or right-click → Bundle into a cable). They're drawn as a sheath that fans out into the coloured cores at each end. Give the cable a label and description (e.g. 3G1.5), and drag the orange dots on a selected cable to move where the cores fan out. For a cable coming in from outside, put a loose part such as the Mains plug at the far end.
  • One-ended cables: when the other end isn't on the drawing, click Cable under Add in the toolbar (or right-click a terminal → Cable from here…), click the terminals its cores go to, and press Enter. The sheath runs off to a free end; fill in Goes to (e.g. "Pump P1") to label it. Each core is a wire, referenced as C1-1, C1-2…
  • Bus bars: click Bus bar under Add in the toolbar, then click the terminals to bridge (or drag along a row), and press Enter. The bar is drawn through them and counts as part of the circuit.
  • Terminal blocks have two bus bar slots (the small squares in the middle) that take bus bars but not wires. To bridge alternate blocks, sweep along a row of slots, then click Keep 1st, 3rd… or Keep 2nd, 4th…. A dot marks each block a bar connects to, so a bar passing over a block without a dot skips it.
  • A selected wire also lights up the rest of its circuit in lighter blue: every wire connected to it, including through the other side of a terminal block. Which terminals are connected inside a part is set with Link in the object type designer.
  • Select whole circuit selects everything in it. Select daisy chain selects only the wires and bus bars joined at the same terminals, such as a jumper chain along the tops of a strip, without crossing to the other side of the terminal blocks.
  • Circuit names: select a wire and type a Circuit name (e.g. +24V). The whole circuit takes the name, and it shows in the wire list.
  • Connector labels: select a part and type a label next to a terminal under Terminals. The label is drawn at the terminal as a boxed tag, so you don't have to draw a wire from where it comes from (handy for power feeds). Terminals and wires with the same name are treated as one circuit.

Your own objects

  • + New type opens the designer. Set the size in millimetres, then click where each terminal goes or add a whole row at once.
  • Add a grid of terminals in the designer places blocks like a 2 × 16 header or an IC. Numbering can wrap by rows or columns, go around like an IC (counter-clockwise or clockwise), or use row letters (A1… B1…), starting from any corner.
  • In the designer, drag over empty space to select several terminals, then drag one of them to move them all. Shift+click adds to the selection, the arrow keys nudge, Ctrl+D copies, Delete removes, and Ctrl+Z undoes.
  • Set Mounting to Loose for parts that aren't on a DIN rail, like connectors on the enclosure. The library's Enclosure connectors group has some ready-made ones (tag prefix X).
  • The library guide covers every setting, a worked example, sharing libraries and the file format.
  • Give terminals the same Link value when they're connected inside the part, such as both sides of a terminal block or a power supply's two +V terminals.
  • Set a terminal's Type to Bus bar slot for a point that takes bus bars only.
  • Editing a type updates every part that uses it.

Right-click menu

  • Right-click a part, terminal, wire, bus bar, rail or note for the things you can do with it. Right-click empty space to paste there, add a rail or note there, undo or fit the view.
  • Right-clicking something already in a multiple selection keeps the selection, so the menu applies to all of it.

Wire profiles

A profile is a named wire type. Wires assigned to a profile take its colour, stripe, size and conductor, and editing a profile here updates all of them. Changing a wire by hand makes it a custom wire again.
